feat: Add options trade tracking to trade journal

Extends the trade journal to support options trades alongside stock trades,
enabling comprehensive tracking of multi-leg strategies with IV and delta metrics.

## Features Added

### Database Schema Updates (models.py)
- Added `trade_type` field: 'stock' or 'option'
- New options-specific fields:
  * `option_strategy`: long_call, cash_secured_put, pmcc, iron_condor, bull_call_spread, other
  * `option_expiration`: Expiration date
  * `option_strike`: Primary strike (or short strike for spreads)
  * `option_strike_2`: Long strike for spreads (optional)
  * `option_type`: call or put
  * `option_dte`: Days to expiration at entry
  * `option_iv`: Implied volatility at entry (%)
  * `option_delta`: Delta at entry

### P&L Calculation
- Options P&L now correctly multiplies by 100 (contract multiplier)
- Formula: `(exit_premium - entry_premium) * contracts * 100`
- Stock P&L remains unchanged: `(exit_price - entry_price) * shares`

### UI Enhancements (routes.py)
- **Trade Type Selector**: Dropdown to choose Stock or Option
- **Dynamic Form Fields**: 
  * Labels change based on trade type
  * "Shares" → "Contracts" for options
  * "Entry Price" → "Entry Premium (per contract)" for options
- **Collapsible Options Section**: 
  * Hidden by default, appears when "Option" selected
  * Includes all options-specific inputs
  * JavaScript toggle for smooth UX

### Options Form Fields
- Strategy dropdown with common strategies
- Expiration date picker
- Strike price inputs (supports spreads with 2 strikes)
- Option type (Call/Put)
- DTE, IV, and Delta tracking
- All fields optional to accommodate various strategies

### Backup/Restore
- Updated JSON backup to include all new options fields
- Backward compatible with existing stock-only trades
- Graceful handling of missing fields during restore

## Usage

1. Navigate to http://localhost:5002/journal/new
2. Select "Option" from Trade Type dropdown
3. Fill in standard trade details (symbol, date, contracts, premium)
4. Options Details section appears automatically
5. Enter strategy, strikes, expiration, IV, delta
6. Save trade - P&L calculated correctly for options
